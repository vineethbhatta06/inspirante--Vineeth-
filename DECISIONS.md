# DECISIONS.md

## 1. Why I Chose Flutter

I chose Flutter because it allows building a complete Android application using a single codebase while providing a modern UI framework and excellent support for local database integration through SQLite.

---

## 2. One Decision I Made That Was Not Explicitly Required

I added a class summary section showing:

* Total number of students
* Average class attendance percentage

to provide a quick overview for the teacher.

---

## 3. One Thing I Would Improve With More Time

If given more time, I would implement following.

Currently, student records are pre-seeded into the database and cannot be added, edited, or removed through the user interface.

An improved version would allow teachers to:

* Add new students
* Edit student information
* Remove students
* Import student lists from a file
